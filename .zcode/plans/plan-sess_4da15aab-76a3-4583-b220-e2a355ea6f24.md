## Part 2 — Feature: the Skip Monster (monster-type plumbing + first type)

**Mechanics** (as confirmed): a skip monster wears a folding-screen cover showing a decoy letter X. Kill note = **two ahead** in the cycle. Pressing the **next** note (one ahead) slices the cover off (no score, timer keeps running) revealing the true demon showing the note one cycle away — which is then slain by the same two-ahead note. Any other key = wrong strike. Direct two-ahead press slays it in one.

**Plumbing — `js/monsters.js`**
- `pickMonsterType()`: `Math.random() < settings.skipMonsterChance ? 'skip' : 'normal'` — the documented extension point for future types.
- `createMonsterData(note)` factory used by **both** `spawnDemon` and `spawnWave` (replaces the duplicated `{note, answer, el}` literals):
  - normal: `{ type:'normal', note, answer: nextLetter(note), el:null }`
  - skip: `{ type:'skip', note, revealKey: nextLetter(note), answer: nextLetter(nextLetter(note)), el:null }`
- `state.current` keeps tracking the **displayed** note (the cover letter for skips), preserving the no-repeat rule. Advanced waves roll the 10% chance per monster independently.

**Config plumbing — `js/config.js`**
- `skipMonsterChance: 0.1` added to `OPTIONS_DEFAULTS` (0–1 fraction).
- New `clampFraction()` helper beside the existing clamps; read in `loadOptions`, written in `saveOptions` (persisted, just no UI control yet — "configure later").

**Rendering — `js/monsters.js` + `style.css`**
- `createDemon(note, depth, type)`; for skip, add a `skip` class and cover markup. The `.body` underneath shows the **real** note (hidden behind the cover); the `.cover` shows the decoy letter.
- CSS `.demon.skip .cover`: folding-screen (屏風) — paper panels with ink border, vertical fold-line gradient, rope strap, big decoy letter, `z-index` above the eyes. Distinct entrance (drop-in bounce) + stiffer idle rock vs the normal wobble, so it reads as a different monster at a glance. Portrait sizing inherits existing `.demon` rules.
- Reveal (`.demon.skip.revealing`): the cover's slash line flashes, then the two panels split and fall away (each half carries a clipped copy of the letter), revealing the demon's eyes + real note with a small pop. JS removes the cover after ~450ms.
- `.slain` unchanged — a directly-slayed covered monster flips away with its cover on.

**Input — `js/game.js` `handleKey`**
- Before the wrong-strike branch: if `target.type === 'skip' && !target.revealed && letter === target.revealKey` → `revealCover(target)` (monsters.js): plays slash sound + "見破った!" popup, triggers the split animation, marks `target.revealed = true`; no score, `awaiting` and timer untouched.
- Otherwise unchanged: `letter === target.answer` → HIT; else `gameOver('WRONG STRIKE')`. After reveal, pressing the reveal key again is a normal wrong strike (the revealed demon now displays that very note) — consistent with normal rules.
